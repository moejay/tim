# Parts Core — v1 Spec

## Overview

Defines the base part system: the trait/interface all parts implement, the parts registry, and the core ball and wall/floor/barrier parts.

## Part Trait

Every game part implements this interface:

```
trait Part {
    fn id(&self) -> PartId;
    fn kind(&self) -> PartKind;
    fn display_name(&self) -> &str;
    fn category(&self) -> PartCategory;

    // Spatial
    fn position(&self) -> Vec2;
    fn set_position(&mut self, pos: Vec2);
    fn bounds(&self) -> AABB;
    fn collider(&self) -> Collider;

    // Physics
    fn physics_body(&self) -> Option<&PhysicsBody>;
    fn physics_body_mut(&mut self) -> Option<&mut PhysicsBody>;
    fn is_static(&self) -> bool;

    // Visual
    fn render_data(&self) -> RenderData;  // sprites, unicode chars, colors
    fn flip_state(&self) -> FlipState;    // normal, flipped_h, flipped_v

    // Interactions
    fn on_collision(&mut self, other: &dyn Part, contact: &Contact) -> Vec<GameEvent>;
    fn on_tick(&mut self, dt: f32, world: &World) -> Vec<GameEvent>;

    // Editor
    fn is_resizable(&self) -> bool;
    fn resize(&mut self, size: Vec2);
    fn is_flippable(&self) -> bool;
    fn flip(&mut self);
    fn is_programmable(&self) -> bool;
    fn programming_options(&self) -> Vec<ProgramOption>;
    fn set_program(&mut self, option: &str, value: ProgramValue);

    // State
    fn is_locked(&self) -> bool;
    fn set_locked(&mut self, locked: bool);
    fn is_destructible_by_dynamite(&self) -> bool;
}
```

## Balls

All balls are dynamic physics objects (non-static). Core properties:

| Ball | Mass | Elasticity | Density | Gravity Response | Radius (px) |
|---|---|---|---|---|---|
| Bowling Ball | 7.0 | 0.1 | 8.0 | AlwaysFalls | 16 |
| Cannonball | 6.0 | 0.0 | 10.0 | AlwaysFalls | 12 |
| Basketball | 0.6 | 0.75 | 0.5 | Normal | 14 |
| Soccer Ball | 0.45 | 0.6 | 0.4 | Normal | 13 |
| Baseball | 0.15 | 0.3 | 1.5 | Normal | 6 |
| Tennis Ball | 0.06 | 0.8 | 0.3 | Normal | 5 |
| Super Ball | 0.1 | 1.1 | 0.8 | Normal | 7 |
| Pinball | 0.08 | 0.15 | 8.0 | AlwaysFalls | 5 |
| Pool Ball | 0.17 | 0.9 | 2.0 | ZeroGravity | 6 |
| Programmable Ball | custom | custom | custom | Custom | 8 |

### Super Ball Special Behavior

- Elasticity > 1.0 means it gains energy on each bounce
- Cap max velocity to prevent infinite acceleration: `MAX_BALL_SPEED = 2000.0` px/s
- Trajectory becomes chaotic on angled surfaces (naturally emerges from high elasticity + angle)

### Pool Ball Special Behavior

- Unaffected by gravity (floats in place until struck)
- Moves like a pool ball: momentum-based, no gravity pull
- Loses momentum to friction over time, eventually stops
- Programmable surface number: 0–9 (cosmetic only)
- Bounces off surfaces until momentum is lost

### Programmable Ball

- UI sliders for: mass (0.01–10.0), elasticity (0.0–1.5), density (0.1–10.0), friction (0.0–1.0)
- Default values: mass=1.0, elasticity=0.5, density=1.0, friction=0.3

## Walls, Floors & Barriers

All walls/floors are static physics objects.

### Resizable Walls

These walls can be stretched horizontally and vertically:

| Wall | Destructible by Dynamite | Friction |
|---|---|---|
| Brick Wall | Yes | 0.4 |
| Yellow Brick Wall | Yes | 0.4 |
| Cinder Block Wall | Yes | 0.5 |
| Greco-Roman Wall | No | 0.3 |
| Wooden Wall | Yes | 0.5 |
| Log Wall | No | 0.6 |
| Caution Wall | No | 0.9 (high friction) |
| Sand Wall | No | 0.7 |
| Pipe Wall | No | 0.2 |
| Curved Pipe Wall | No | 0.2 |

#### Resize Behavior

- Minimum size: 16×16 px
- Maximum size: 400×400 px
- Resize by dragging edge handles
- Collider updates to match new size

#### Curved Pipe Wall

- Four rotation states: 0°, 90°, 180°, 270°
- Used for corners and lips
- Indestructible

### Fixed-Size Barriers

| Barrier | Size (px) | Destructible |
|---|---|---|
| Grass Floor | 64×16 | No |
| Scaffold Barrier | 32×48 | No |
| Wooden Barrier | 24×24 | No |
| Lattice Archway | 48×64 | No |
| Marble Archway | 48×64 | No |

## Inclines & Ramps

- All inclines are static, indestructible
- Stretchable: adjusting length changes the angle/steepness
- Flippable: mirror for left/right slope direction
- Collider: polygon (triangle or trapezoid depending on stretch)

| Incline | Size Settings | Friction |
|---|---|---|
| Brick Incline | 5 lengths: very steep → nearly level | 0.4 |
| Yellow Brick Incline | 5 lengths | 0.4 |
| Granite Incline | 5 lengths | 0.3 |

### Stretch Settings

```
enum InclineSize {
    VeryShort,   // ~30px wide, very steep (~70°)
    Short,       // ~60px wide, steep (~55°)
    Medium,      // ~100px wide, moderate (~40°)
    Long,        // ~150px wide, gentle (~25°)
    VeryLong,    // ~200px wide, nearly level (~10°)
}
```

Height is constant (~40px); width determines slope angle.

## Parts Registry

Central registry that knows all part types and can instantiate them:

```
struct PartsRegistry {
    templates: HashMap<PartKind, PartTemplate>,
}

impl PartsRegistry {
    fn create_part(&self, kind: PartKind, position: Vec2) -> Box<dyn Part>;
    fn all_kinds(&self) -> Vec<PartKind>;
    fn kinds_in_category(&self, cat: PartCategory) -> Vec<PartKind>;
    fn display_name(&self, kind: PartKind) -> &str;
}
```

## Placement Rules

- Parts cannot overlap other parts (collision check on placement)
- Parts snap to pixel grid (no sub-pixel placement)
- Parts can be placed anywhere within world bounds
- Static parts (walls, floors) are placed before simulation starts
- Dynamic parts may be placed on top of static parts (e.g., ball on wall)
