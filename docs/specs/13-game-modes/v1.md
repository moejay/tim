# Game Modes — v1 Spec

## Overview

Four distinct game modes, each with different rules and UI.

## Mode 1: Puzzle Play (Single-Player Campaign)

### Entry Flow
1. Main Menu → "Puzzle Play"
2. Sign-in screen: enter/select player name
3. Puzzle selection: grid of puzzles organized by difficulty tier
4. Selected puzzle loads with pre-built machine and parts bin

### Gameplay Loop
```
1. Read goal text
2. Browse parts bin
3. Drag parts from bin to playfield
4. Position, flip, resize, program parts as needed
5. Press Green Flag to run simulation
6. Watch chain reaction
7. If goal met → Win screen (Same Puzzle / Replay / Next Puzzle)
8. If goal not met → Press flag again to stop, adjust parts, retry
```

### Rules
- Fixed parts cannot be moved or removed
- Player parts can be placed, moved, returned to bin freely before running
- No time limit for placement
- Machine can be run and stopped unlimited times
- "Show Solution" available at any time (lightbulb button)
- Broom button removes all player-placed parts from playfield

### Puzzle Tiers
| Tier | Puzzle Count | Unlock Condition |
|---|---|---|
| Tutorial | ~10 | Always available |
| Easy | ~35 | Complete 5 Tutorial puzzles |
| Medium | ~35 | Complete 20 Easy puzzles |
| Hard | ~35 | Complete 20 Medium puzzles |
| Expert | ~35+ | Complete 20 Hard puzzles |

### Progress Tracking
- Per-player save data
- Each puzzle: solved/unsolved status
- Solved indicator: glowing lightbulb icon
- Password revealed on completion
- Bonus timers: two countdown timers per level, completing before expiry adds to score

## Mode 2: Professor Tim's Workshop (Level Editor / Sandbox)

### Entry Flow
1. Main Menu → "Workshop"
2. Empty playfield with full parts catalog
3. Full editing tools available

### Building Workflow (10 Steps)
1. **Place parts**: drag from complete parts catalog (all parts available, up to 79 per puzzle)
2. **Write goal**: click goal text area, type description
3. **Lock parts**: click padlock button to lock all placed parts (become fixed/immovable)
4. **Unlock player parts**: selectively unlock specific parts (these go to Parts Bin for the player)
5. **Select music**: choose from track list
6. **Adjust physics**: set gravity and atmospheric pressure sliders
7. **Add hints**: place pointing-finger tooltips with custom text
8. **Program solutions**: use checkered flag handles to define win conditions
9. **Test**: run the machine to verify it works
10. **Save**: save with 8-character filename

### Solution Programming

#### For Non-Moving Parts
- Select part → click checkered flag handle
- Set desired final state:
  - `Occupied` — something must be in/on this part
  - `Vacant` — nothing should be in/on this part
  - `Activated` — part must be in active state (lit candle, spinning gear, etc.)

#### For Moving Parts
- Select part → click checkered flag handle
- Define exit condition:
  - `OffTop` — must exit top of screen
  - `OffBottom` — must exit bottom of screen
  - `OffScreen` — must exit any edge
  - `AtPosition(rect)` — must end up within defined rectangle
- Define state condition:
  - `Ignited` — must be on fire
  - `Launched` — must have launched
  - `Popped` — must be popped (balloons)
  - `Destroyed` — must be destroyed

### Parts Bin Editor
- Click parts bin area → enters edit mode
- Bomb button: removes all parts from bin
- Click individual parts to add/remove from bin
- Quantity adjustment: +/- buttons per part

### Scenery System
- Decorative non-functional elements
- Categories: trees, clouds, buildings, creatures, landscapes, space objects
- Layering: front (over parts) or back (behind parts)
- Does not interact with physics

### File Operations
- Save: 8-character filename, directory navigation
- Load: browse saved puzzles
- Load solved puzzles: any previously completed puzzle can be loaded and modified

### Duplication
- Right-click any placed part → creates unlimited copies (Workshop only)
- Useful for quickly building repetitive structures

## Mode 3: Head-to-Head (Two-Player Hotseat)

### Setup Flow
1. Main Menu → "Head-to-Head"
2. Configuration:
   - Games per match: 1–9 (selection buttons)
   - Time per turn: 10–90 seconds (slider, 10s increments)
   - Player 1 name entry
   - Player 2 name entry
3. Puzzle selection: 50 dedicated 2-player puzzles + all single-player puzzles

### Turn Rules
```
Turn 1 (Player 1):
  - Place ONE part from the bin
  - Cannot move existing parts on first turn
  - End Turn button or timer expiration

Subsequent Turns:
  - Place ONE part from bin  — OR —  Move ONE existing part
  - Cannot do both
  - Parts cannot be returned to bin once placed
  - End Turn button or timer expiration
  - Green flag can be pressed to test machine mid-turn
```

### Visual Indicators
- Background tint: Red = Player 1's turn, Blue = Player 2's turn
- Timer display: countdown for current player
- Turn indicator: current player name highlighted

### Win Condition
- First player to achieve the puzzle goal wins the round
- If a player presses Green Flag and the goal is met, that player wins
- If neither player can solve it, round is a draw

### Match Scoring
- Scoreboard: tracks wins per player across the match
- Match winner: player with most round wins when all games complete
- Tie possible if equal wins

### Strategy Elements
- Blocking: place parts to prevent opponent's chain from working
- Deception: create setups that appear helpful but aren't
- Positioning: avoid placing parts that give the opponent an advantage

## Mode 4: Guided Tour (Tutorial)

### Structure
- Linear walk-through of game mechanics
- Professor Tim narrates (text bubbles, voice-over in CD version)
- Step-by-step puzzle construction

### Tutorial Stages
1. **Controls**: how to drag parts, use handles
2. **Basic physics**: dropping a ball, bouncing, rolling
3. **Simple machine**: ramp → ball → basket
4. **Mechanical parts**: gears, belts, levers
5. **Rope and pulleys**: basic rope connections
6. **Electrical**: power chain basics
7. **Animals**: cat-mouse interaction
8. **Ignition**: flashlight → magnifying glass → fuse → dynamite
9. **Advanced**: combining multiple systems

### Per-Stage Flow
1. Text explanation of the concept
2. Partially built machine with one missing part
3. Highlighted placement zone (flashing outline)
4. Player places the part
5. Machine runs automatically
6. Success animation → next stage

## Mode Transitions

```
MainMenu
  ├── PuzzlePlay → PuzzleSelect → Puzzle → [Win/Retry]
  ├── Workshop → Editor → [Save/Load/Test]
  ├── HeadToHead → Setup → Puzzle → [Win/NextRound/MatchEnd]
  └── GuidedTour → Stage1 → Stage2 → ... → Complete
```

## Shared Systems

All modes share:
- Physics engine
- Parts system
- Rendering
- Audio

Mode-specific:
- Puzzle Play: goal evaluation, progress tracking, solution display
- Workshop: editing tools, solution programming, save/load
- Head-to-Head: turn management, timers, scoring
- Guided Tour: scripted sequences, narration
