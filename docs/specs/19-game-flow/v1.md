# Game Flow — v1 Spec

## Overview

Complete game flow from application launch through all screens, menus, dialogs, and UI interactions. Covers sign-in, main menu, puzzle play, workshop, head-to-head, guided tour, tutorial, and all supporting dialogs.

## 1. Application Startup Flow

```
Launch → Sign-In Window → Main Menu
```

### Sign-In Window

| Element | Description |
|---|---|
| Name Field | Text input at top for typing player name |
| Player List | Scrollable list of registered players below the name field |
| Done Button | Confirms selection and proceeds to Main Menu |
| Help Button | Opens context help for the sign-in screen |

### Sign-In Behavior
- Click a name in the player list to select it (populates the name field)
- Type a new name not in the list → confirmation dialog: "Yes" to create new player
- Entering "Guest" as the name → no progress is saved
- After sign-in completes → transition to Main Menu

## 2. Main Menu

Seven clickable picture buttons arranged in a grid, plus a persistent Game Options button.

### Menu Buttons

| # | Button | Action | Description |
|---|---|---|---|
| 1 | Puzzle Play | → Puzzle Play Screen | Solve puzzles built by Professor Tim (150+ puzzles) |
| 2 | Professor Tim's Workshop | → Workshop Screen | Build and modify puzzles from scratch |
| 3 | Head-to-Head | → Head-to-Head Chooser | Two-player competitive puzzle-solving |
| 4 | Guided Tour | → Guided Tour Screen | Automated demos of game mechanics |
| 5 | Sign-In | → Sign-In Window | Switch active player |
| 6 | Tutorial (Walk-Through) | → Tutorial Screen | Step-by-step puzzle building guide |
| 7 | Player Preferences | → Preferences Dialog | Toggle game settings |

### Game Options Button
- Persistent button available from within any game screen
- Returns to Main Menu when clicked

## 3. Player Preferences Dialog

Five toggle buttons. Active state indicated by red color.

| Toggle | Default | Description |
|---|---|---|
| Ambient Animation Shown | On | Idle wiggling/twinkling on parts |
| Scenery Parts Displayed | On | Show decorative scenery parts |
| Background Animation On | On | Animated background elements |
| Show Info Handles | On | Magnifying glass icon appears on part hover |
| Sound Effects On | On | Play sound effects |

### Three Regions
- **Control Panel** (left strip): vertical column of picture buttons
- **Play Area** (center): main playfield where parts are placed and simulation runs
- **Parts Bin** (right strip): scrollable list of available parts with quantity indicators

### Puzzle Goal Bar
- Bottom bar displaying text that describes the puzzle objective

## 5. Control Panel Buttons (Puzzle Play)

Arranged top to bottom in left strip.

| # | Button | Icon | Function |
|---|---|---|---|
| 1 | Load | Floppy disk | Opens Load Puzzle menu |
| 2 | Music | Guitar | Opens Music & Sound Effects menu |
| 3 | Globe | Earth globe | Opens Gravity/Pressure/Background Color viewer (read-only) |
| 4 | Broom | Broom | Removes all unlocked/player-placed parts, returns them to bin |
| 5 | Help | Question mark | Activates context-sensitive help mode |
| 6 | Hints | Pointing finger | Shows hint markers on playfield |
| 7 | Solution | Lightbulb | Shows Professor Tim's solution |

## 6. Parts Bin (Right Strip)

### Top Area
- **Toggle Control Panel**: button to show/hide the left Control Panel
- **Run Button**: green flag icon; starts simulation. Changes to animated checkered flag while running
- **Game Options**: returns to Main Menu

### Parts List
- Scrollable list of parts
- Each entry: part icon + quantity number
- Scroll arrows at top and bottom of list

### Bottom Area
- **Scenery Toggle**: tree button, toggles scenery part visibility
- Additional scroll arrows for browsing parts

## 7. Placing Parts

### Placement Flow
1. Click a part in the Parts Bin → part icon attaches to cursor
2. Move cursor to desired position on playfield
3. Click to place the part
4. Red X indicator appears if placement overlaps or is too close to another part

### Duplication
- Right-click on a placed part → creates a duplicate copy at cursor

### Quantity Rules
- **Puzzle Play**: limited copies per part (quantity shown in Parts Bin, decrements on placement)
- **Workshop**: unlimited copies of all parts

## 8. Part Handles

Handles appear when hovering over or selecting a placed part. Displayed as small icons around the part.

### Standard Handles (All Modes)

| Handle | Icon | Function |
|---|---|---|
| Recycle | Trash can | Returns part to Parts Bin |
| Flip | Curved arrows | Rotates or mirrors the part |
| Size | Double arrows | Stretches or shrinks the part |
| Programming | Computer icon | Opens part programming dialog (12 programmable parts only) |
| Info | Magnifying glass | Shows part description popup |

### Workshop-Only Handles

| Handle | Icon | Function |
|---|---|---|
| Checkered Flag | Checkered flag | Opens solution recognition programming |
| Padlock | Padlock | Toggles lock/unlock state for this part |

## 9. Running the Simulation

### Start
- Click green flag (top-right of Parts Bin area) → simulation begins
- Green flag changes to animated checkered flag

### Stop
- Click checkered flag → simulation stops, all parts reset to pre-run positions

### Puzzle Solved
When the puzzle goal is met, a "You solved the puzzle!" popup appears with three options:

| Option | Icon | Action |
|---|---|---|
| Same Puzzle | Left arrow | Reset and try the same puzzle again |
| Replay Solution | Replay icon (center) | Watch the winning solution replay |
| Next Puzzle | Right arrow | Load the next puzzle in the current tier |

## 10. Load Menu / Puzzle Selection

Accessed via the floppy disk button on the Control Panel.

### Puzzle List View
- Shows puzzles for the currently selected difficulty tier
- Each puzzle entry has a lightbulb indicator:
  - Off = unsolved
  - Glowing = solved
- Scroll arrows for navigating the puzzle list
- **Double-click** a puzzle title to quick-load it

### Buttons
- **Load**: load selected puzzle
- **Cancel**: return to playfield
- **More Puzzles**: opens the Load Selection Window

### Load Selection Window (7 Categories)

| # | Category | Description |
|---|---|---|
| 1 | Easy Puzzles | Beginner difficulty |
| 2 | Medium Puzzles | Intermediate difficulty |
| 3 | Hard Puzzles | Advanced difficulty |
| 4 | Really Hard Puzzles | Expert difficulty |
| 5 | Tutorial Puzzles | Teach how individual parts work |
| 6 | Head to Head Puzzles | Designed for competitive play |
| 7 | Homemade Puzzles | User-created puzzles |

- **Cancel** button returns to the puzzle list view

## 11. Help System

### Activation
1. Click the question mark button on the Control Panel → help mode activates
2. Cursor changes to indicate help mode
3. Click any part or picture button → popup with description text appears
4. After viewing, click question mark again → stay in help mode for another query
5. Click "Done" to exit help mode

## 12. Hints System

### Activation
1. Click the pointing finger button on the Control Panel
2. Hint markers appear on the playfield (pointing finger icons at specific positions)

### Viewing Hints
1. Click a pointing finger hint marker → popup with hint text and magnifying glass icon
2. Click "Done" to close the hint popup

## 13. Music & Sound Effects Menu

Accessed via the guitar button on the Control Panel.

### Three Panels

| Panel | Controls |
|---|---|
| **Music Selection** (top) | Scroll arrows + song name display, musical note button to restart track, switch to turn music off |
| **Sound Effects Preview** (middle) | "POW" button to preview, gadget sound name display with scroll arrows to browse |
| **Volume & Exit** (bottom) | Volume up/down arrows, help button, "Done" button |

## 14. Gravity, Pressure & Background Color Dialog

Accessed via the globe button on the Control Panel.

### Controls

| Control | Type | Description |
|---|---|---|
| Gravity Slider | Vertical slider | Planet icons along slider — up = less gravity, down = more gravity |
| Pressure Slider | Vertical slider | Space/beach icons — up = more air pressure, down = less air pressure |
| Background Color | Arrow selector | Scroll through available colors with preview window |
| Help | Button | Context help for this dialog |
| Done | Button | Close dialog |

### Mode Behavior
- **Puzzle Play**: gravity and pressure are **read-only** (view current puzzle settings only)
- **Workshop**: gravity and pressure are **fully editable**

## 15. Professor Tim's Workshop

Full sandbox mode with all Puzzle Play features plus additional Workshop-only capabilities.

### Extra Control Panel Buttons (Workshop)

| Button | Icon | Function |
|---|---|---|
| Gravity/Pressure | Globe | Fully editable gravity, pressure, and background color |
| Lock Parts/Hints | Padlock + finger | Opens Lock Parts / Hints window |
| Test Drive | Stick shift | Preview puzzle as a player would experience it |
| Scenery | Green tree | Switches Parts Bin to Scenery Bin |
| Program Solutions | Checkered flag | Access solution programming via part handles |

### Ten-Step Puzzle Building Workflow

| Step | Action | Details |
|---|---|---|
| 1 | Go to Workshop | Select from Main Menu |
| 2 | Build a machine | Place parts on playfield (minimum 5 parts required) |
| 3 | Write Goal Description | Click bottom goal text window, type objective text |
| 4 | Lock all parts | Click padlock button → locks every part on screen |
| 5 | Unlock solution parts | Click padlock handle on specific parts to unlock them → they move to Parts Bin |
| 6 | Select music | Guitar button → choose background track |
| 7 | Set gravity & pressure | Optional — globe button to adjust physics settings |
| 8 | Add hints | Optional — pointing finger in Lock/Hints window |
| 9 | Program solution | Checkered flag handle on relevant parts → define win conditions |
| 10 | Save puzzle | Floppy disk → Save menu |

## 16. Scenery System (Workshop)

### Activation
- Click green tree button → Parts Bin switches to Scenery Bin
- Click tree again → switches back to regular Parts Bin
- Click tree a third time → hides all scenery on playfield

### Scenery Part Types
- Trees, clouds, critters, buildings, landscapes, space elements
- Non-functional: purely decorative, no physics interactions

### Scenery Part Handles

| Handle | Function |
|---|---|
| Flip | Rotate/mirror |
| Size | Stretch/shrink |
| Programming | Open part programming |
| Recycle | Delete scenery part |
| Move to Back | Send to back rendering layer |
| Move to Front | Bring to front rendering layer |

## 17. Lock Parts / Hints Window (Workshop)

### Lock Controls

| Control | Function |
|---|---|
| Locked padlock icon | Lock ALL parts on screen |
| Unlocked padlock icon | Unlock ALL parts on screen |
| Individual part padlock handle | Toggle lock/unlock for a single part |

### Hint Creation (5-Step Process)

1. Click the padlock/pointing finger button to open the Lock/Hints window
2. Click the picture of Secret Agent Tim
3. Click "New" → pointing finger cursor attaches to mouse → position on playfield
4. Click to place hint → empty text window appears → type hint text
5. Click "Hide" when done

### Hint Management
- **New**: create another hint (repeat steps 3-5)
- **Show**: display existing hints to move or delete them
- **Hide**: hide hint markers from view

## 18. Solution Programming (Workshop)

### Non-Moving Parts (fixed during simulation)

1. Click checkered flag handle on the part → solution menu opens
2. **"Not In Solution"** toggle: click to exclude/include this part from win condition
3. Scroll arrows to select desired state (e.g., "Vacant" → "Occupied" for Mel's House)
4. **"Advanced"** button → opens Part Count, Delay, and Position sub-menus
5. Click "Done" when finished

### Moving Parts (balls, animals, etc.)

Radio button selection:
- **Not In Solution**: part is ignored for win checking
- **Off Top**: part must exit the top of the playfield
- **Off Bottom**: part must exit the bottom of the playfield
- **Off Screen**: part must exit any edge of the playfield

Additional:
- Scroll arrows for physical state (e.g., "Fireworks" → "Not Launched" / "Launched")
- **"Advanced"** button → Part Count, Delay, Position sub-menus

### Advanced Solution Menu

| Option | Function |
|---|---|
| Part Count | Set how many of this part type must match the condition (e.g., "Pop 4 of 5 balloons") |
| Delay | Set time before checking solution — run puzzle, click when desired state is reached to capture the delay |
| Position | Draw a rectangle on the playfield defining the target area the part must be within |

## 19. Test Drive Mode (Workshop)

### Activation
- Click stick shift button → enters Test Drive mode
- All unlocked parts move to Parts Bin
- Hints and solution recognition become active
- Puzzle plays exactly as it would in Puzzle Play mode

### Exit
- Click stick shift button again → returns to Workshop editing mode

## 20. Saving Puzzles (Workshop)

### Save Flow
1. Click floppy disk button (top of Control Panel)
2. Click "Save" disk icon (red arrow indicator)
3. Fill in fields:
   - **Title**: type puzzle name (displayed in load menus)
   - **File**: auto-generated 8-character filename (editable for custom name)
4. Click "Save" button

### Save Location
- Default: Homemade Puzzles directory
- **Change Directory** button to select alternate save location
- File list shows existing puzzles in current directory

## 21. Head-to-Head Mode

### Setup: Head-to-Head Chooser Dialog

| Control | Description |
|---|---|
| Number of Games | Scroll selector, range 1-9 |
| Player 1 Name | Green text field for entering name |
| Player 2 Name | Green text field for entering name |
| Player 1 Time per Turn | Scroll selector, range 10-90 seconds |
| Player 2 Time per Turn | Scroll selector, range 10-90 seconds (independent — allows handicap) |
| OK | Start the match |
| Cancel | Return to Main Menu |

### Scoreboard (Displayed During Play)

| Element | Description |
|---|---|
| Turn Indicator | Left side red = Player 1's turn, right side blue = Player 2's turn |
| Timer | Countdown showing seconds remaining in current turn |
| Win Counter | Rounds won by each player |
| End Turn Button | Top right — manually end current turn early |
| Puzzle Goal | Text description of the objective |

### Head-to-Head Rules

1. Gold popup announces which player goes first
2. **First player's first turn**: take ONE part from the bin and place it anywhere on the playfield
3. **Subsequent turns**: take one part from bin AND/OR move one already-placed part
4. Cannot return parts to the bin once placed
5. Cannot move a part after placing a new one from bin in the same turn
6. Turn ends when: timer expires OR player clicks "End Turn"
7. Green flag can be pressed mid-turn to test the current machine
8. First player whose machine solves the puzzle wins the round (even if their timer runs out while the machine is still running)
9. **Strategic elements**: block opponent's setup, create deceptive configurations, avoid giving opponent advantages
