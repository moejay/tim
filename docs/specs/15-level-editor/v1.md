# Level Editor (Workshop) — v1 Spec

## Overview

Professor Tim's Workshop is a full-featured level editor for creating custom puzzles. This spec covers the editor-specific workflows beyond what's in the UI spec.

## Editor States

```
enum EditorState {
    Building,          // placing and arranging parts
    GoalEditing,       // editing goal text
    LockingParts,      // locking/unlocking parts
    PartsBinEditing,   // editing which parts appear in player's bin
    SolutionProgramming, // defining win conditions
    HintPlacing,       // placing hint tooltips
    PhysicsAdjusting,  // gravity/pressure sliders
    MusicSelecting,    // choosing background music
    Testing,           // running the machine to test
    Saving,            // save dialog
    Loading,           // load dialog
}
```

## Ten-Step Puzzle Building Workflow

### Step 1: Place Parts

- Full parts catalog available (all part types)
- Maximum 79 parts per puzzle
- Part counter displayed: `Parts: 23/79`
- Placement: click part in catalog, click playfield position
- All standard part handles available (flip, resize, program)
- Right-click to duplicate any placed part (unlimited copies in Workshop)

### Step 2: Write Goal Description

- Click goal text area at top of screen
- Text input field appears
- Type the puzzle goal (e.g., "Get the bowling ball into the basket")
- Press Enter to confirm
- Max 200 characters

### Step 3: Lock All Parts

- Click the padlock button in the control panel
- All currently placed parts become locked (fixed/immovable)
- Locked parts display a small lock icon overlay
- These become the "pre-built machine" that the puzzle player cannot move

### Step 4: Unlock Player Parts

- Click individual locked parts to unlock them
- Unlocked parts are removed from the playfield and added to the Parts Bin
- These become the parts the player must place to solve the puzzle
- Set quantity per part type in the Parts Bin

### Step 5: Select Music

- Open music dialog
- Scrollable list of available tracks
- Preview: click track to hear it
- Select: click OK to confirm choice
- Music plays during puzzle gameplay

### Step 6: Adjust Physics (Optional)

- Open Globe dialog
- Gravity slider: 0.0 – 2.0
- Atmospheric Pressure slider: 0.0 – 2.0
- Preview: changes are applied immediately to the editor playfield
- Default: both at 1.0 (normal Earth conditions)

### Step 7: Add Hints (Optional)

- Enter hint placement mode
- Click position on playfield to place hint marker
- Type hint text in dialog
- Hint appears as a pointing-finger icon
- Multiple hints can be placed
- Hints are numbered in order of placement
- Player sees hints one at a time via the Hint button

### Step 8: Program Solution Recognition

- Enter solution programming mode
- Click the checkered flag handle on relevant parts

#### Non-Moving Parts
- Set desired final state:
  - **Occupied**: something must be in/on this part when puzzle is solved
  - **Vacant**: nothing should be in/on this part
  - **Activated**: part must be in its active state

#### Moving Parts
- Set exit condition:
  - **Off Top**: object must exit the top of the screen
  - **Off Bottom**: object must exit the bottom
  - **Off Screen**: object must exit any edge
  - **At Position**: define a rectangle — object must be within it
- Set state condition:
  - **Ignited**: object must be on fire
  - **Launched**: rocket/cannonball must have launched
  - **Popped**: balloon must be popped
  - **Destroyed**: object must be destroyed

#### Position Rectangle Definition
1. Click first corner of rectangle on playfield
2. Click opposite corner
3. Rectangle is displayed as a dashed outline
4. Object must be within this rectangle AND at rest to count as solved

### Step 9: Test

- Press Green Flag to run the machine
- Machine plays exactly as a puzzle player would experience it
- Win condition is evaluated — if met, "Puzzle Solved!" confirmation appears
- If not met, editor can stop simulation and adjust
- Iterative testing: build → test → adjust → test

### Step 10: Save

- Save dialog:
  ```
  ┌──────────────────────────┐
  │ Save Puzzle              │
  │                          │
  │ Filename: [________]     │
  │ (max 8 characters)       │
  │                          │
  │ Directory: /puzzles/     │
  │ [Browse...]              │
  │                          │
  │ [Save]  [Cancel]         │
  └──────────────────────────┘
  ```
- Filename: max 8 characters, alphanumeric + underscore
- Default directory: `puzzles/custom/`
- File format: JSON (see Puzzle System spec)
- Overwrite confirmation if file exists

## Parts Bin Editor

### Entering Edit Mode
- Click the Parts Bin area in Workshop mode
- Bin switches to edit mode

### Edit Mode UI
```
┌──────────┐
│ EDIT BIN │
│          │
│ 💣 Clear │  ← Bomb button: removes all parts from bin
│          │
│ ○ Ball   │  ← Toggle: click to add/remove from bin
│ ● Wall   │  ← Filled circle = in bin
│ ○ Ramp   │
│ ● Gear   │
│          │
│ Ball: ×3 │  ← Quantity: +/- buttons
│  [-][+]  │
│          │
│ [Done]   │
└──────────┘
```

### Operations
- **Bomb (Clear)**: removes ALL parts from the bin (start fresh)
- **Toggle**: click part type to add/remove from player's bin
- **Quantity**: adjust how many of each part the player receives
- **Done**: exit edit mode, return to normal building

## Scenery System

### Scenery Categories
| Category | Examples |
|---|---|
| Nature | Trees, bushes, flowers, grass patches |
| Sky | Clouds, sun, moon, stars |
| Buildings | Houses, skyscrapers, barns |
| Creatures | Birds, butterflies, fish (decorative only) |
| Landscape | Mountains, hills, rivers |
| Space | Planets, asteroids, nebulae |

### Scenery Properties
- No physics collision
- No interaction with game parts
- Two layers: Front (over parts) and Back (behind parts)
- Toggleable visibility (Scenery button in control panel)
- Positioned freely on playfield

### Scenery Placement
- Separate scenery catalog (accessible via Scenery button)
- Click scenery item, click playfield to place
- Toggle layer: right-click placed scenery → Front/Back
- Delete: drag to recycle handle or Delete key

## Load Previously Solved Puzzles

- Any previously completed puzzle can be loaded into Workshop
- Opens with all parts (fixed and player) placed in solved positions
- All parts start unlocked — can be modified freely
- Useful for creating variations of existing puzzles

## Validation

Before saving, the editor validates:
- [ ] At least 5 parts placed
- [ ] Goal text is not empty
- [ ] At least one win condition is programmed
- [ ] At least one part is in the Parts Bin (player needs something to place)
- [ ] Filename is valid (1–8 chars, alphanumeric + underscore)

Warnings (non-blocking):
- No hints placed
- Default gravity/pressure (might be intentional)
- No music selected
