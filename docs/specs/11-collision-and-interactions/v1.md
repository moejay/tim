# Collision & Interactions — v1 Spec

## Overview

Defines the complete interaction matrix: how every part type interacts with every other part type. This is the rules engine that makes the Rube Goldberg chains work.

## Interaction Categories

### 1. Weight on Lever (Teeter-Totter)

| Trigger | Effect |
|---|---|
| Object falls on one end | Other end catapults objects sitting on it |
| Rope attached to one end, pulled | Lever tips in pull direction |
| Heavy object placed on one end | Lever tips and stays tipped |

**Physics**: torque = mass × gravity × distance_from_pivot

### 2. Air on Windmill

| Air Source | Effect on Windmill |
|---|---|
| Electric Fan (powered) | Continuous spin in air direction |
| Bike Pump / Bellows (compressed) | Burst spin (decays over ~2s) |
| Teapot Steam | Continuous spin while steaming |

**Requirements**: air source must be within range and directed at windmill blades

### 3. Belt Drive System

Any spinning part can drive any other spinning part via belt:

| Driver (source of rotation) | Driven (receives rotation) |
|---|---|
| Gear (spinning) | Gear, Conveyor, Generator, Jack-in-the-Box |
| Windmill (spinning) | Gear, Conveyor, Generator, Jack-in-the-Box |
| Electric Motor (powered) | Gear, Conveyor, Generator, Jack-in-the-Box |
| Mouse Exercise Wheel (active) | Gear, Conveyor, Generator, Jack-in-the-Box |
| Mandrill Motor (shade open) | Gear, Conveyor, Generator, Jack-in-the-Box |
| Electric Mixer (powered) | Gear, Conveyor, Generator, Jack-in-the-Box |

**Rules**:
- Belt must connect the two parts (within max stretch distance)
- Rotation direction transfers directly through belt (same direction)
- Interlocking gears reverse direction (opposite rotation)
- Speed transfers 1:1 through belt; gear ratios apply for interlocking gears

### 4. Rope + Pulley Mechanics

| Configuration | Effect |
|---|---|
| Weight → rope → pulley → lighter object | Lighter object is pulled upward |
| Weight → rope → pulley → lever arm | Lever arm is pulled |
| Weight → rope → pulley → drawstring | Drawstring is pulled (activates lava lamp) |
| Weight → rope → pulley → gun trigger | Gun fires |
| Weight → rope → pulley → shade | Shade opens (mandrill motor activates) |

### 5. Animal Interactions

| Interaction | Condition | Effect |
|---|---|---|
| Cat sees Mouse | Pokey within 200px line-of-sight of Mort | Pokey chases Mort |
| Cat sees Broken Bowl | Pokey within 200px of broken fishbowl | Pokey walks toward bowl |
| Mouse sees Cheese | Mort within 150px of cheese | Mort runs toward cheese |
| Cat catches Mouse | Pokey reaches Mort | Mouse disappears (eaten) |
| Alligator eats Mouse | Mort enters Edison's jaw zone | Mouse disappears, alligator laughs |
| Alligator eats Mel | Mel enters Edison's jaw zone | Mel disappears, alligator laughs |
| Alligator ignores Cat | Pokey enters jaw zone | Nothing happens |
| Mouse activates Wheel | Mort within 30px of exercise wheel | Wheel mouse starts running |
| Alligator tail bounce | Object lands on tail | Object bounced upward (~500 px/s) |
| Alligator jaw fling | Object passes jaw detection zone | Object flung in facing direction |

### 6. Ignition Chain

| Source | Target | Effect |
|---|---|---|
| Magnifying glass beam | Fuse | Fuse ignites |
| Magnifying glass beam | Candle | Candle lights |
| Burning fuse end | Adjacent fuse | Adjacent fuse ignites |
| Burning fuse end | Dynamite fuse | Dynamite ignites |
| Burning fuse end | Cannon fuse | Cannon ignites |
| Burning fuse end | Rocket fuse | Rocket ignites |
| Burning fuse end | Candle | Candle lights |
| Candle flame | Fuse (contact) | Fuse ignites |
| Candle flame | Another candle | Other candle lights |
| Laser beam | Fuse | Fuse ignites |
| Laser beam | Candle | Candle lights |
| Rocket trail | Fuse | Fuse ignites |
| Rocket trail | Candle | Candle lights |
| Rocket trail | Balloon | Balloon pops |

### 7. Light and Power

| Source | Target | Effect |
|---|---|---|
| Flashlight beam | Magnifying glass | Focused beam produced |
| Lava lamp light | Magnifying glass | Focused beam produced |
| Flashlight beam | Solar panel | Panel powered |
| Lava lamp light | Solar panel | Panel powered |
| Candle light | Solar panel | Panel powered (short range) |
| Laser beam | Laser-activated plug | Plug powered (if correct color) |

### 8. Balloon Interactions

Balloons are popped by:

| Popping Agent | Mechanism |
|---|---|
| Spinning gear | Contact with spinning gear teeth |
| Scissors (closing) | Contact during closing animation |
| Tack | Contact with sharp point |
| Dynamite explosion | Within blast radius |
| Candle flame | Direct contact |
| Rocket trail | Direct contact during flight |
| Laser beam | Direct hit |
| Gun bullet | Direct hit |

Balloons are NOT popped by:
- Falling objects (balls, etc.) — they bounce off
- Static gears (not spinning)
- Walls, floors, ramps

### 9. Destruction

| Destroyer | Destroyable Targets | Non-Destroyable |
|---|---|---|
| Dynamite explosion | Brick, Yellow Brick, Cinder Block, Wooden walls | Inclines, Metal Piping, Earth, Caution, Greco-Roman, Log, Sand |
| Cannonball impact | Glass boxes, Fishbowl | Walls, floors (damages but doesn't destroy) |
| Strong impact | Fishbowl (velocity > 100 px/s), Glass box, Cardboard box | Most parts |

### 10. Vacuum Interactions

| Object Type | Vacuum Effect |
|---|---|
| Any ball | Sucked in and consumed |
| Mort the Mouse | Sucked in and consumed |
| Pokey the Cat | Sucked in and consumed |
| Mel | Sucked in (counts as death) |
| Candle | Sucked in |
| Static parts | No effect |
| Balloon | No effect (buoyant, resists suction) |

### 11. Objects as Ramps

These parts can serve as ramp/deflector surfaces for rolling/bouncing objects:

- Teeter-totter (when tilted)
- Bellows / Bike pump
- Boxing glove (body, not punch)
- Gun (body)
- Fan (body, when not blowing the object away)
- Electric motor
- Flashlight
- Metal piping curves
- Vacuum cleaner (body)
- Pinball bumper

## Collision Layers

```
enum CollisionLayer {
    Default,        // balls, boxes, dynamic objects
    Static,         // walls, floors, static parts
    Animal,         // cats, mice, Mel
    Projectile,     // cannonballs, bullets, toast
    Trigger,        // detection zones (no physical collision)
    Rope,           // rope segments
    Laser,          // laser beams (raycast, not collision)
    Air,            // airflow zones (no physical collision)
}
```

### Layer Interaction Matrix

| Layer | Collides With |
|---|---|
| Default | Static, Default, Animal, Trigger |
| Static | Default, Animal, Projectile |
| Animal | Static, Default, Animal, Trigger |
| Projectile | Static, Default, Animal |
| Trigger | Default, Animal (detection only, no physics response) |
| Rope | (special handling — tension model, not collision) |
| Laser | (raycast — not collision-based) |
| Air | (zone-based — not collision-based) |

## Event System

Interactions generate events that the game loop processes:

```
enum GameEvent {
    // Collision events
    BalloonPop(PartId),
    FuseIgnite(PartId),
    CandleLight(PartId),
    CandleExtinguish(PartId),
    Explosion(Vec2, f32),           // position, radius
    WallDestroyed(PartId),
    FishbowlBreak(PartId),

    // Animal events
    MouseEaten(PartId),             // mouse was eaten
    MelDied(PartId),                // Mel died
    MelEnteredHouse(PartId, PartId), // Mel, House
    MouseReachedHole(PartId),
    MouseReachedCheese(PartId),
    CatCaughtMouse(PartId, PartId),

    // Mechanical events
    GunFired(PartId),
    CannonFired(PartId),
    RocketLaunched(PartId),
    JackInTheBoxOpened(PartId),
    BoxingGlovePunched(PartId),

    // State events
    ObjectExitedWorld(PartId, ExitDirection),
    ObjectEnteredContainer(PartId, PartId),
    ObjectAtRest(PartId, Vec2),
    SwitchFlipped(PartId),

    // Electrical events
    PowerStateChanged(PartId, bool),

    // Rope events
    RopeCut(RopeId, Vec2),
}
```

## Update Priority Order

Each simulation tick processes interactions in this order:

1. Physics integration (forces, velocity, position)
2. Collision detection and response
3. Rope/cable tension updates
4. Belt drive propagation
5. Electrical power propagation
6. Laser beam tracing
7. Light and ignition checks
8. Animal AI updates
9. Air/fluid zone effects
10. Event processing (pops, ignitions, explosions, deaths)
11. Goal condition checks
