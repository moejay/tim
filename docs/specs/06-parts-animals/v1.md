# Animals & Characters — v1 Spec

## Overview

Animals and characters are autonomous agents with behavior-driven AI. They respond to stimuli, chase/flee from other entities, and interact with the environment.

## Pokey the Cat

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 24×20px
- **Mass**: 0.8 (heavier than bucket)
- **Direction**: left or right (initial facing)
- **States**: `Idle`, `Walking`, `Chasing`, `Startled`

### Behavior State Machine

```
Idle:
  - Sits still, occasional meow animation
  - Transitions:
    → Chasing: if mouse detected within 200px line-of-sight
    → Chasing: if broken fishbowl detected within 200px line-of-sight
    → Startled: if hit by any object

Chasing:
  - Walks toward target (mouse or broken fishbowl)
  - Speed: 80 px/s
  - Transitions:
    → Idle: if target is no longer visible (blocked, consumed, or out of range)
    → Startled: if hit by any object

Startled:
  - Shrieks, fur stands up animation
  - Duration: 1.0 seconds
  - Transitions:
    → Idle: after duration expires
    → Chasing: if target visible after recovery

Walking:
  - Walks in facing direction until hitting obstacle
  - Speed: 60 px/s
  - Turns around at walls
```

### Interactions
- **Catches mouse**: if Pokey reaches Mort, mouse is consumed (disappears)
- **Attracted to broken fishbowl**: walks toward broken fishbowl like chasing a mouse
- **Does NOT get eaten by alligator**: Edison ignores Pokey
- **Feels gravity**: falls off edges, can land on platforms

## Mort the Mouse

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 10×8px
- **Mass**: 0.02 (very light)
- **Direction**: left or right (initial facing)
- **States**: `Idle`, `Fleeing`, `SeekingCheese`, `Eaten`, `Safe`

### Behavior State Machine

```
Idle:
  - Sits still
  - Transitions:
    → Fleeing: if cat detected within 200px
    → SeekingCheese: if cheese detected within 150px and no cat threat
    → Eaten: if alligator mouth contact

Fleeing:
  - Runs away from cat
  - Speed: 70 px/s (slower than cat — cat catches mouse if no obstacles)
  - Direction: opposite of cat's position
  - Transitions:
    → Idle: if cat no longer in range
    → Eaten: if alligator contact
    → Safe: if reaches mouse hole

SeekingCheese:
  - Runs directly toward cheese
  - Speed: 60 px/s
  - Transitions:
    → Idle: if reaches cheese (both stop, mouse sits next to cheese)
    → Fleeing: if cat detected (cat overrides cheese attraction)
    → Eaten: if alligator contact

Eaten:
  - Consumed by alligator — mouse disappears
  - Triggers alligator laugh animation

Safe:
  - Entered mouse hole — mouse disappears
  - Counts as "saved" for goal purposes
```

### Interactions
- **Activates mouse exercise wheel**: proximity within 30px scares mouse inside wheel
- **Tiny**: fits through small gaps that larger animals cannot
- **Eaten by alligator**: consumed on jaw contact

## Cheese

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 12×10px
- **Mass**: 0.1
- **Gravity response**: Normal (falls normally, rises under weak gravity)

### Behavior
- Passive — does not move on its own
- Attracts Mort the Mouse within 150px
- Does NOT get consumed — both Mort and cheese sit still when Mort reaches it

## Edison Alligator

### Properties
- **Type**: static part (does not move from position)
- **Size**: 64×32px
- **Direction**: left or right (flippable)

### Behavior

#### Tail
- Continuously bounces up and down during simulation
- Objects dropped on tail bounce back up
- Tail bounce force: ~500 px/s upward impulse
- Oscillation: ~2 Hz (2 full cycles per second)

#### Jaw
- Snaps at passing objects and animals
- Detection zone: ~40px in front of mouth
- Snap animation: 0.3s
- Objects hit by jaw are flung in the facing direction (~600 px/s)

#### Eating
- **Eats**: Mort the Mouse, Mel Schlemming
- **Does NOT eat**: Pokey the Cat
- Eat detection: object must enter mouth area during jaw snap
- After eating: signature laugh animation (1.5s)

## Mel Schlemming

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 16×24px
- **Mass**: 0.5
- **Programmable**: `Walk` (default), `Run`, `Stationary`
- **Direction**: left or right (initial facing)
- **States**: `Walking`, `Running`, `Stationary`, `EnteringHouse`, `Dead`

### Behavior

```
Walking:
  - Walks in facing direction at 50 px/s
  - At wall: turns around
  - At Mel's House: enters (transition to EnteringHouse)
  - At edge/drop: walks off and falls
  - Transitions:
    → Dead: if falls more than 150px
    → Dead: if hits wall at speed > 200 px/s
    → Dead: if eaten by alligator
    → EnteringHouse: if reaches Mel's House

Running:
  - Same as Walking but at 100 px/s
  - Higher fall death threshold: 200px (momentum carries him)

Stationary:
  - Does not move until pushed
  - If pushed off edge, begins walking in push direction

EnteringHouse:
  - Mel walks into house, disappears
  - House lights up, chimney smokes, Mel visible through window
  - Permanent state

Dead:
  - Mel disappears with death animation
  - Permanent state
```

### Death Conditions
- Fall distance > 150px (walking) or 200px (running)
- Impact with wall at speed > 200 px/s
- Eaten by Edison Alligator

## Mel's House

### Properties
- **Type**: static part
- **Size**: 48×48px
- **Programmable**: appearance toggle — suburban house or log cabin
- **States**: `Empty`, `Occupied`

### Behavior
- When Mel walks past: Mel enters, house transitions to `Occupied`
- Occupied state visuals: lights on, chimney smoke, Mel visible through window
- Only Mel interacts with it — other objects treat it as a solid wall

## Bill's Fish Tank (Bob the Fish)

### Properties
- **Type**: static part (until broken)
- **Size**: 20×24px
- **States**: `Intact`, `Broken`

### Behavior
- **Intact**: fish swims inside (cosmetic animation)
- **Breaking**: any object impact with sufficient force (velocity > 100 px/s) breaks the bowl
- **Broken**: broken bowl remains, fish flaps on ground (dies after 3 seconds)
- **Cat attraction**: broken bowl attracts Pokey the Cat (walks toward it like chasing mouse)

## Mouse Hole

### Properties
- **Type**: static part
- **Size**: 16×16px

### Behavior
- Mort the Mouse enters when walking past it
- Mouse disappears — counted as "safe" for puzzle goals
- Only Mort interacts with it

## Leprechaun

### Properties
- **Type**: static part
- **Size**: 24×32px
- **Behavior**: decorative/interactive character, no puzzle mechanics

## AI Update Order

Each tick:
1. Update Edison Alligator tail oscillation and jaw snap timing
2. Update Pokey: detect targets (mouse, broken bowl), update movement
3. Update Mort: detect threats (cat), detect attractors (cheese), update movement
4. Update Mel: walk/run logic, check for house entry, check death conditions
5. Check eat interactions (alligator jaw + mouse/mel, cat + mouse)
6. Update fishbowl break detection
