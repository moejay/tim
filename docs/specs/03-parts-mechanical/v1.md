# Mechanical Parts — v1 Spec

## Overview

Mechanical parts convert, transfer, and redirect physical motion. They form the backbone of Rube Goldberg chains.

## Gears (Metal Cog)

### Properties
- Static position (does not fall)
- Radius: 20px (default), resizable: 16–32px
- Has rotation state: `angular_velocity: f32` (radians/s)
- Initially stationary unless driven

### Behavior
- **Interlocking**: adjacent gears (within 4px gap) automatically interlock — one spinning drives the other in opposite direction
- **Belt-driven**: can be driven by a belt connection from another spinning part
- **Balloon popping**: a spinning gear pops any balloon that contacts it
- Gear ratio: `driven_speed = driver_speed * (driver_radius / driven_radius)`

### Connections
- Input: belt from any spinning part, or adjacent gear
- Output: belt to other parts, or adjacent gear

## Pulley

### Properties
- Static position
- Radius: 12px
- Allows rope to thread through it

### Behavior
- Redirects rope/cable direction
- Rope passes over the pulley wheel, changing angle
- Frictionless (ideal pulley) — no force loss
- Multiple pulleys can chain to create complex rope routes

## Belt (Fan Belt)

### Properties
- Connects exactly two rotating parts
- Maximum stretch distance: 200px between connected parts
- Visual: thin band between two parts

### Behavior
- Transfers rotation from one part to another
- Same rotation direction (not reversed like meshing gears)
- Speed transfer: 1:1 ratio (no gear ratio via belt)
- If stretch distance exceeded, belt breaks (disconnects)

### Connection Rules
- Can connect: gear ↔ gear, gear ↔ windmill, gear ↔ electric motor, gear ↔ mouse wheel, gear ↔ mandrill motor, gear ↔ conveyor, gear ↔ generator, gear ↔ jack-in-the-box, and any combination thereof
- Placement: click first part, then click second part to create belt

## Teeter-Totter (Seesaw/Lever)

### Properties
- Static pivot point at center
- Length: 80px default, resizable: 60–120px
- Pivot friction: low (easy to tip)
- Two ends can receive rope attachments

### Behavior
- Tips when weight is applied to one side
- Angular physics: torque = force × distance from pivot
- Objects on the high end are catapulted when the other end is struck
- Can function as a ramp/deflector when tilted
- Rope can attach to either end — pulling rope tips the lever

### Catapult Mechanics
```
catapult_force = impact_force * (impact_distance / other_end_distance)
launch_angle = lever_angle + 90°  // perpendicular to lever surface
```

## Conveyor Belt

### Properties
- Static position
- Resizable: 4 length settings (64px, 128px, 192px, 256px)
- Surface speed determined by driving part
- Direction determined by driving part's rotation

### Behavior
- Objects on the surface are moved in the conveyor direction
- Must be connected to a spinning part via belt to operate
- Without belt connection: acts as a static platform
- Surface friction is high — objects don't slide against direction easily

## Trampoline

### Properties
- Static position
- Width: 48px
- Elasticity surface: 1.2 (objects bounce higher than they fell)

### Behavior
- Objects bounce on contact with the surface
- Straight-down fall → straight-up bounce
- Angled impact → angled bounce (reflection across surface normal)
- Bounce height = `fall_height * 1.2` (gains energy)
- Cap max bounce velocity: 1500 px/s

## Jack-in-the-Box

### Properties
- Static position
- Size: 32×32px
- Has lid that opens when wound

### Behavior
- Must be driven by a spinning part via belt
- After sufficient rotation (~3 full turns), lid springs open
- Objects on the lid are catapulted upward/outward
- Catapult direction depends on orientation (flippable)
- Catapult force: strong (comparable to bowling ball drop on teeter-totter)

## Windmill

### Properties
- Static position
- 4 blades, radius: 24px
- Rotation direction: depends on flip state

### Behavior
- Spins when blown by air (fan, bellows/bike pump, teapot steam)
- Air must hit the blades to spin — position relative to air source matters
- Can be flipped to change rotation direction
- Drives other parts via belt when spinning
- Spin speed proportional to air force

## Mandrill Motor (Monkey Bike)

### Properties
- Static position
- Size: 48×40px
- Has shade/blind mechanism with rope attachment point

### Behavior
- Monkey rides bicycle when shade is open (banana visible)
- Shade starts closed by default
- Shade has rope attachment point — pull rope to open shade
- Once open, monkey pedals → generates rotation for belt connections
- If hit on head by falling object: monkey stops pedaling briefly (2 seconds), stars animation
- Rotation speed: constant when pedaling

## Mouse Exercise Wheel

### Properties
- Static position
- Radius: 20px
- Contains a mouse that faces left or right

### Behavior
- Mouse direction (left/right) determines spin direction
- Activates when startled: any object hitting the wheel or landing within 30px
- Once activated, mouse runs continuously for the rest of the simulation
- Drives other parts via belt
- Spin speed: constant when running

## Scissors

### Properties
- Static position
- Two states: open and closed
- Size: 24×16px

### Behavior
- Starts open
- Closes when an object presses on the handle or sharp end
- When closing: cuts any rope passing through the scissor point
- Also pops balloons on contact (when closing)
- Stays closed after closing

## Hedge Trimmers

### Properties
- Static position
- Size: 32×12px

### Behavior
- Cuts rope on contact (always active, no trigger needed)
- Does NOT cut steel cable

## Tin Snips

### Properties
- Static position
- Size: 24×12px

### Behavior
- Cuts rope AND steel cable on contact
- Only tool that can cut steel cable

## Automatic Boxing Glove

### Properties
- Static position
- Size: 24×32px
- Direction: left or right (flippable)

### Behavior
- Trigger: any object touching the flat back end
- Action: punches outward in the facing direction
- Punch force: sends movable objects flying (~1200 px/s)
- Resets after punch (can fire multiple times)
- Punch animation: ~0.3 seconds

## Vacuum Cleaner

### Properties
- Static position
- Size: 40×32px
- Requires electrical power (must be plugged in)

### Behavior
- When powered: creates suction zone (radius ~60px from opening)
- Sucks any gravity-affected object into the opening
- Sucked objects disappear (consumed)
- Placing a surface over the opening blocks suction but traps objects against it
- Objects held against a covered opening do not get consumed

## Pinball Bumper

### Properties
- Static position
- Radius: 12px

### Behavior
- Bounces objects away on contact
- Impulse direction: away from bumper center
- Impulse force: strong (~800 px/s added velocity)
- Lights up briefly on contact (visual feedback)

## Tack

### Properties
- Static position
- Size: 8×8px

### Behavior
- Sharp point pops balloons on contact
- Multiple tacks placed together create a walking surface for animals
- Can form curved ramps when placed in sequence
- Does not affect balls or other non-balloon objects
