# Gadgets & Specialty Items — v1 Spec

## Overview

Miscellaneous parts that don't fit neatly into other categories. Each has unique mechanics.

## Captain Z Super Phazer (Ray Gun)

### Properties
- **Type**: static part
- **Size**: 32×16px
- **Direction**: left or right (flippable)
- **Programmable**: blast quantity (1–5 shots)
- **Has**: rope attachment point

### Behavior
- Fires energy blasts when triggered (via rope pull or object hitting trigger)
- Each blast travels in facing direction at ~1800 px/s
- Blasts interact like bullets: hit movable objects and push them
- Blast count decrements; when empty, no more shots

## Egg Timer

### Properties
- **Type**: static part
- **Size**: 16×20px
- **Programmable**: delay duration (1.0s – 10.0s in 0.5s increments)

### Behavior
- Starts counting down when the simulation begins (or when triggered by object impact)
- After delay: spring-loaded arm deploys, pushing/flipping nearby objects
- Arm extends ~20px in one direction
- Force: moderate (~400 px/s impulse)

## Eye Hook

### Properties
- **Type**: static part
- **Size**: 8×12px

### Behavior
- Provides a fixed attachment point for ropes
- Rope threads through the hook
- Used to redirect rope along walls/ceilings
- Similar to pulley but without rotation — just a fixed anchor point

## Boat Cleat (Metal Loop)

### Properties
- **Type**: static part
- **Size**: 12×8px
- **Immovable**: cannot be displaced by any force

### Behavior
- Stable, immovable rope attachment point
- When rope needs a fixed anchor that won't move under load, tie it here
- Rope attaches and holds firm regardless of tension

## Laundry Basket (Bottomless Birdcage)

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 28×32px
- **Mass**: 1.2 (heavier than bucket)
- **Has**: rope attachment point at top

### Behavior
- Container with no floor — can be dropped onto animals to trap them
- Trapping: if dropped onto Pokey or Mort, animal is enclosed and cannot escape
- Trapped animals continue their idle animations but cannot move
- Useful for preventing cat from reaching mouse
- Can be suspended by rope to create a drop-trap

## Gun (Revolver)

### Properties
- **Type**: static part
- **Size**: 28×20px
- **Direction**: left or right (flippable)
- **Has**: trigger with rope attachment point (behind the handle)

### Behavior
- Fires when trigger is pulled via rope
- Rope must attach behind handle and pull from behind (toward the back of the gun)
- Pulleys can redirect rope angle for correct pull direction
- Bullet: travels instantly (hitscan) in aimed direction
- Bullet hits: cats, fish bowls, balls, Mel, balloons
- Gun body itself can serve as a ramp/deflector for rolling objects
- Single shot — fires once

## Anti-Gravity Pad

### Properties
- **Type**: static part
- **Size**: 32×8px

### Behavior
- Reverses gravity for objects resting on or passing over it
- Objects above the pad experience upward gravity
- Effect zone: ~16px above the pad surface
- Objects leaving the zone return to normal gravity
- Useful for redirecting falling objects upward

## Santa Lamp

### Properties
- **Type**: static part
- **Size**: 20×28px
- **Behavior**: decorative lamp, provides ambient light (cosmetic)

## Balloon

### Properties
- **Type**: dynamic part (buoyant — rises)
- **Size**: 20×28px
- **Mass**: 0.01
- **Gravity**: buoyant (rises under normal gravity)
- **Programmable**: design/color (4 options)
- **Has**: rope attachment point at bottom tie

### Behavior
- Rises due to buoyancy when not tethered
- Can be held in place by rope
- Popped by: spinning gears, scissors, tacks, dynamite blast, candle flame, laser beam, gun bullet, rocket trail
- NOT popped by: balls, falling objects, animals, fans
- When popped: disappears with pop animation, rope falls free

## Hot Air Balloon

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 32×40px
- **Mass**: 0.5
- **Has**: rope attachment point at bottom basket

### Behavior
- Starts cold and stationary on the ground
- When heat source is applied (candle, flame, rocket trail): begins rising
- Carries objects in the basket
- Can be anchored by rope to limit ascent
- Three states: Cold (grounded), Heating (heat applied), Rising (airborne)

## Boxes (5 Variants)

### Properties
- **Type**: dynamic parts (feel gravity)
- **Programmable**: variant selection

| Variant | Size (px) | Mass | Destructible |
|---|---|---|---|
| Glass Box | 24×24 | 0.3 | Yes (shatters on strong impact) |
| Wooden Box | 28×28 | 0.5 | Yes (dynamite) |
| Wicker Box | 24×24 | 0.2 | No |
| Metal Box | 28×28 | 1.0 | No |
| Cardboard Box | 24×24 | 0.1 | Yes (any impact) |

### Behavior
- Containers that can hold small objects (balls, animals)
- Objects landing inside stay contained (if box has floor)
- Can be stacked
- Glass box shatters when hit hard enough (velocity > 300 px/s)
- Cardboard box crumples on any significant impact

## Containers & Structures

### Bucket (Pail)

- **Type**: dynamic part (feels gravity)
- **Size**: 20×20px
- **Mass**: 0.5
- **Has**: rope attachment point at handle
- **Behavior**:
  - Catches and holds objects (balls, animals, cannonballs)
  - Must be attached to rope to hang suspended
  - Weight increases as objects land inside
  - Weight change affects rope/pulley dynamics

### Leaky Bucket

- **Type**: dynamic part (feels gravity)
- **Size**: 20×20px
- **Initial mass**: 1.5 (full of water)
- **Programmable**: leak rate (slow, medium, fast)
- **Has**: rope attachment point at handle
- **Behavior**:
  - Starts heavy (full of water), gets lighter as water drains
  - Leak rates: slow = 0.1 mass/s, medium = 0.3 mass/s, fast = 0.6 mass/s
  - Minimum mass: 0.3 (empty bucket weight)
  - Weight differential creates rope/pulley dynamics (counterweight puzzles)

## Color Block

### Properties
- **Type**: static part
- **Size**: 16×16px (not resizable)
- **Programmable**: 44 color options

### Behavior
- Decorative scenery/background block
- Solid collision (acts as a small wall)
- Used for custom level aesthetics

## Message Computer

### Properties
- **Type**: static part
- **Size**: 16×24px per character
- **Programmable**: display character — alphabet A–Z, numerals 0–9, symbols

### Behavior
- Displays a single character
- Multiple message computers spell out words/messages
- Purely decorative — no physics interactions

## Teapot

### Properties
- **Type**: dynamic part (feels gravity)
- **Size**: 24×20px
- **Mass**: 0.4
- **Direction**: steam goes up-left or up-right (flippable)

### Behavior
- Produces steam when heated from below (usually by a lit candle placed underneath)
- Steam direction: up-right (default) or up-left (flipped)
- Steam pushes the teapot backward (recoil) — slides away from steam direction
- Steam stream can spin windmills and push lightweight objects
- Three states: Cold (idle), Heating (heat applied, warming up), Boiling (producing steam)
- Can be placed on conveyor belts or other surfaces
