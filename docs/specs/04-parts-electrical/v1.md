# Electrical System — v1 Spec

## Overview

The electrical system provides power generation, distribution, and consumption. Electrical devices must be plugged into powered outlets to function.

## Power Sources

### Generator

- **Type**: static part
- **Size**: 32×32px
- **Has**: one outlet (two sockets)
- **Activation**: must be connected to a spinning part via belt
- **Output**: generates power when the connected part is spinning
- **Visual**: wheel spins when belt drives it, outlet glows when active

### Electrical Outlet (Always-On)

- **Type**: static part
- **Size**: 16×24px
- **Has**: two sockets
- **Activation**: always powered — no input needed
- **Use**: place devices directly, no power chain required

### Electric Switch & Outlet (Light Switch)

- **Type**: static part
- **Size**: 16×32px
- **Has**: physical toggle switch + two sockets
- **Activation**: switch must be flipped by a falling/moving object striking it
- **Switch orientation**: up or down (flippable) — determines which direction activates
- **State**: off until switch is flipped, then stays on permanently

### Solar Panel (Light-Powered Outlet)

- **Type**: static part
- **Size**: 32×24px
- **Has**: two sockets
- **Activation**: requires a nearby light source (flashlight, lava lamp, or candle) within ~80px and line-of-sight
- **State**: powered only while light source is active and in range
- **Visual**: panel glows when receiving light

### Laser-Activated Plug

- **Type**: static part
- **Size**: 16×24px
- **Has**: two sockets
- **Programmable**: select which laser color activates it (red, green, blue, or any mixed color)
- **Activation**: powered when hit by the correct color laser beam
- **State**: powered only while laser is hitting it

## Powered Devices

All powered devices must be plugged into a powered outlet to function.

### Electric Fan

- **Size**: 24×24px
- **Behavior**: blows continuous directional airflow when powered
- **Direction**: left or right (flippable)
- **Air force**: pushes objects and spins windmills within ~120px range
- **Air force falloff**: linear, full force at fan → zero at max range

### Electric Motor

- **Size**: 20×20px
- **Behavior**: spins a gear/cog when powered
- **Direction**: clockwise or counter-clockwise (flippable)
- **Output**: drives other parts via belt connection
- **Speed**: constant RPM when powered

### Toaster

- **Size**: 24×20px
- **Programmable**: toast delay — light (1.5s), medium (3.0s), burnt (5.0s)
- **Behavior**: after delay, launches two pieces of toast upward
- **Toast launch**: ~600 px/s upward velocity, slight spread angle
- **Toast objects**: small dynamic physics objects (mass 0.02, elasticity 0.3)

### Can Opener

- **Size**: 20×16px
- **Behavior**: opens cans when powered (mechanical animation)
- **Interaction**: primarily decorative/goal-based

### Electric Mixer

- **Size**: 20×24px
- **Behavior**: rotates when powered
- **Output**: can drive belts like other spinning parts

## Connection Rules

### Outlet Placement
1. Place the outlet on the playfield first
2. Then place (or drag) the electric device onto the outlet
3. Device snaps to the outlet and shows connection indicator

### Socket System
- Each outlet has exactly **two sockets**
- Each socket can hold one device
- Visual indicator: empty socket = open circle, occupied = filled black circle
- A device can only be plugged into one outlet at a time

### Wiring Visual
- No visible wire between outlet and device — device is placed directly adjacent
- Device must be within 24px of the outlet to connect
- If device is moved away from outlet, connection breaks

## Power Chain Examples

```
Spinning Part → Belt → Generator → [outlet with 2 sockets] → Fan + Motor
                                                              └→ Motor → Belt → Conveyor

Light Source → Solar Panel → [outlet] → Fan

Falling Object → Light Switch → [outlet] → Toaster

Laser → Laser-Activated Plug → [outlet] → Electric Motor
```

## State Model

```
enum PowerState {
    Unpowered,    // no power source active
    Powered,      // receiving power
}

struct Outlet {
    power_state: PowerState,
    socket_a: Option<PartId>,  // connected device
    socket_b: Option<PartId>,  // connected device
}

struct PoweredDevice {
    outlet: Option<PartId>,    // which outlet it's plugged into
    is_active: bool,           // powered AND plugged in
}
```

## Update Logic

Each tick:
1. Update all power sources (check if generators are spinning, switches are flipped, solar panels are lit, lasers are hitting)
2. Propagate power state to outlets
3. Update all connected devices based on outlet power state
4. Devices execute their behavior only when `is_active == true`
