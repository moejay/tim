# Laser System — v1 Spec

## Overview

Lasers emit colored beams that can be redirected with mirrors, mixed with combiners, and used to activate mechanisms, ignite fuses, pop balloons, and power laser-activated plugs.

## Laser Emitters

### Properties (all three colors)
- **Type**: static part
- **Size**: 24×12px
- **Direction**: left, right, up, or down (rotatable in 90° increments)
- **Always on**: beam emits continuously from simulation start

| Laser | Color | RGB |
|---|---|---|
| Red Laser | Red | (255, 0, 0) |
| Green Laser | Green | (0, 255, 0) |
| Blue Laser | Blue | (0, 0, 255) |

### Beam Properties
- Travels in a straight line from emitter
- Infinite range (until hitting an obstacle or leaving the world)
- Zero width for collision purposes (ray, not a thick beam)
- Visual width: 2px with glow effect

## Angled Mirror

### Properties
- **Type**: static part
- **Size**: 16×16px
- **Rotatable**: 4 positions (0°, 90°, 180°, 270°)
- Each position reflects incoming beams at a specific angle

### Reflection Angles

| Mirror Rotation | Incoming Direction | Outgoing Direction |
|---|---|---|
| 0° (/) | Right → | Up ↑ |
| 0° (/) | Down ↓ | Left ← |
| 90° (\) | Left ← | Up ↑ |
| 90° (\) | Down ↓ | Right → |
| 180° (/) | Left ← | Down ↓ |
| 180° (/) | Up ↑ | Right → |
| 270° (\) | Right → | Down ↓ |
| 270° (\) | Up ↑ | Left ← |

### Behavior
- Beam hits mirror surface → reflected in the configured direction
- Mirror can redirect beam through multiple bounces (chain mirrors)
- If beam hits mirror edge (non-reflective side), beam is blocked

## Laser Mixer

### Properties
- **Type**: static part
- **Size**: 24×24px
- **Inputs**: two sides receive beams
- **Output**: one side emits mixed beam

### Color Mixing

| Input A | Input B | Output |
|---|---|---|
| Red | Green | Yellow |
| Red | Blue | Purple/Magenta |
| Green | Blue | Cyan |
| Red | Green + Blue | White |

### Behavior
- Both inputs must be receiving beams simultaneously for mixing
- Output beam emits from the designated output side
- If only one input is active, that color passes through unchanged
- Output beam can be further mixed or redirected by mirrors

## Laser Detector

### Properties
- **Type**: static part
- **Size**: 16×16px
- **States**: `Inactive`, `Active`

### Behavior
- Receives any color laser beam
- When hit by beam: status light turns on (green LED indicator)
- When beam is interrupted: status light turns off
- Primarily used for puzzle goal detection ("activate the laser detector")
- No electrical output — purely a visual indicator and goal trigger

## Laser-Activated Plug

(See also: Electrical System spec)

### Properties
- **Type**: static part
- **Size**: 16×24px
- **Programmable**: activation color (Red, Green, Blue, Yellow, Purple, Cyan, White)
- **Has**: two outlet sockets (like other outlets)

### Behavior
- Powered ONLY when hit by the correct color laser
- Powers connected electrical devices while laser is active
- If laser is interrupted, power is cut immediately
- Useful for conditional power: specific laser paths must be built to power specific devices

## Laser Interactions

| Target | Effect |
|---|---|
| Balloon | Pops on contact |
| Fuse | Ignites on contact |
| Candle (unlit) | Lights the candle |
| Laser-Activated Plug | Powers outlet (if correct color) |
| Laser Detector | Activates indicator |
| Mirror | Reflects beam |
| Laser Mixer | Contributes to color mixing |
| All other parts | Beam is blocked (no effect) |

## Beam Tracing Algorithm

Each tick (or on laser/mirror placement change):

```
fn trace_laser_beam(emitter: &Laser, world: &World) -> Vec<BeamSegment> {
    let mut segments = vec![];
    let mut origin = emitter.position;
    let mut direction = emitter.direction;
    let mut color = emitter.color;
    let max_bounces = 20;  // prevent infinite loops

    for _ in 0..max_bounces {
        // Raycast from origin in direction
        let hit = world.raycast(origin, direction);

        match hit {
            None => {
                // Beam exits world
                segments.push(BeamSegment { start: origin, end: world_edge, color });
                break;
            }
            Some(hit) => {
                segments.push(BeamSegment { start: origin, end: hit.point, color });

                match hit.part.kind() {
                    Mirror => {
                        // Reflect and continue
                        direction = reflect(direction, hit.part.mirror_angle());
                        origin = hit.point;
                    }
                    LaserMixer => {
                        // Add to mixer input, handle in mixer update
                        hit.part.receive_laser(color, direction);
                        break;
                    }
                    Balloon => {
                        // Pop balloon
                        emit_event(GameEvent::BalloonPop(hit.part.id()));
                        break;  // beam stops
                    }
                    Fuse => {
                        emit_event(GameEvent::FuseIgnite(hit.part.id()));
                        break;
                    }
                    Candle => {
                        emit_event(GameEvent::CandleLight(hit.part.id()));
                        break;
                    }
                    LaserActivatedPlug => {
                        hit.part.receive_laser(color);
                        break;
                    }
                    LaserDetector => {
                        hit.part.activate();
                        break;
                    }
                    _ => {
                        // Beam blocked
                        break;
                    }
                }
            }
        }
    }

    segments
}
```

## Performance Notes

- Laser beams only need to be re-traced when:
  - A laser emitter or mirror is moved/placed/removed
  - A blocking object moves into/out of the beam path
- Cache beam paths and invalidate on relevant changes
- Maximum beam bounces capped at 20 to prevent infinite mirror loops
