# UI & Controls — v1 Spec

## Overview

The user interface for building and running machines. Covers the playfield, control panel, parts bin, part interaction handles, and keyboard shortcuts.

### Proportions
- Control Panel: ~60px wide (left edge)
- Parts Bin: ~80px wide (right edge)
- Playfield: remaining width
- Goal Text Bar: ~24px tall (top)

## Main Playfield

### Properties
- 2D side-view workspace
- Background color: selectable from palette (default: sky blue #336699)
- Scrollable: playfield can be larger than visible area
- Default playfield size: 640×400 pixels (scalable)
- Grid: optional snap grid (8px or 16px, toggleable)

### Interactions
- **Click empty space**: deselect current part
- **Click part**: select part (shows handles)
- **Drag part**: move selected part to new position
- **Right-click part**: duplicate (Workshop mode: unlimited; Puzzle Play: if available in bin)
- **Drag from Parts Bin**: place new part from inventory

### Scrolling
- Arrow keys or mouse at screen edges to scroll
- Scroll bounds: playfield edges + margin

## Control Panel (Left Side)

### Buttons (top to bottom)

| Button | Icon | Function | Modes |
|---|---|---|---|
| **Run/Stop** | Green Flag | Start/stop simulation | All |
| **Status** | Checkered Flag | Animates when sim is running | All |
| **Load** | Folder | Open load puzzle dialog | All |
| **Music** | Musical Note | Open music selector | All |
| **Globe** | Earth Globe | Gravity/pressure sliders | Workshop |
| **Broom** | Broom | Remove all player-placed parts | Puzzle Play |
| **Help** | Question Mark | Context-sensitive help mode | All |
| **Solution** | Lightbulb | Show Professor Tim's solution | Puzzle Play |
| **Hint** | Pointing Finger | Show next hint | Puzzle Play |
| **Scenery** | Tree | Toggle scenery visibility | Workshop |

### Button States
- Normal: default appearance
- Hover: highlighted
- Active: pressed/toggled on
- Disabled: grayed out (unavailable in current mode)

### Run/Stop Button Behavior
```
Building state:
  Click → Start simulation
  Button changes to red Stop icon

Running state:
  Click → Stop simulation
  All parts return to pre-run positions
  Button changes back to green Run icon
```

## Parts Bin (Right Side)

### Layout
- Scrollable vertical list
- Each entry shows: part icon + quantity remaining
- Quantity format: `×3` next to icon
- Empty (quantity 0) parts are grayed out

### Interactions
- **Click part**: selects it for placement (cursor becomes part icon)
- **Click playfield**: places the selected part
- **Scroll**: mouse wheel or up/down arrows within bin area

### Category Navigation
Categories are separated by divider lines. Keyboard shortcuts jump to categories:

| Key | Category |
|---|---|
| R | Balls (Rolling objects) |
| W | Walls |
| F | Floors |
| P | Pipes |
| I | Inclines |
| A | Arches |
| O | Pool Stuff |
| G | Gears & Belts |

### Workshop Parts Bin Editor
- Enter edit mode: click parts bin area when in Workshop
- Bomb button: clear all parts from bin
- Click part type: toggle inclusion in bin
- +/- buttons: adjust quantity per part

## Part Interaction Handles

When a part is selected, contextual handles appear around it:

```
         [Flip ↰]
            │
    [Info] ─┼─ [Program]
            │
[Size ↔] ──Part── [Size ↕]
            │
    [Flag] ─┼─ [Lock]
            │
         [Recycle]
```

### Handle Details

| Handle | Icon | Position | Function | Available |
|---|---|---|---|---|
| Recycle | Trash can | Bottom | Return part to bin | Always (player parts) |
| Flip | Curved arrows | Top or corners | Rotate/mirror the part | If part is flippable |
| Size H | Double arrow ↔ | Left/right edges | Stretch horizontally | If part is resizable |
| Size V | Double arrow ↕ | Top/bottom edges | Stretch vertically | If part is resizable |
| Program | Computer | Right side | Open programming UI | If part is programmable |
| Info | Magnifying glass | Left side | Show part description | Always |
| Flag | Checkered flag | Bottom-left | Program solution state | Workshop only |
| Lock | Padlock | Bottom-right | Lock/unlock part | Workshop only |

### Handle Behavior
- Handles appear on part selection, disappear on deselection
- Clicking a handle triggers its function
- Dragging size handles resizes in real-time
- Handles do not appear during simulation (parts can't be edited while running)

## Goal Text Bar

### Display
- Full width bar at top of playfield
- Shows puzzle goal text (e.g., "Pop the balloon")
- In Workshop: clickable — "Click here to enter description" placeholder
- Font: bold, centered, contrasting color against background

### Workshop Editing
- Click to enter text edit mode
- Type goal description
- Press Enter to confirm
- Max length: 200 characters

## Puzzle Status Indicators

### Lightbulb
- Empty outline: puzzle unsolved
- Glowing (filled yellow): puzzle solved
- Displayed next to puzzle title in selection screen

### Checkered Flag Animation
- Static: simulation not running
- Waving animation: simulation running
- Speed of wave indicates simulation is active

## Context-Sensitive Help

### Activation
1. Click Question Mark button (enters help mode)
2. Cursor changes to question mark icon
3. Click any part or UI element
4. Help tooltip/panel appears with description
5. Click again or press Escape to exit help mode

### Help Content
Each part has:
- Name
- Category
- Description (2-3 sentences)
- Key behaviors
- Interaction notes

## Keyboard Shortcuts

| Key | Action |
|---|---|
| Space | Run/Stop simulation |
| Escape | Deselect part / Cancel operation / Exit dialog |
| Delete | Return selected part to bin |
| R, W, F, P, I, A, O, G | Jump to parts bin category |
| Arrow Keys | Scroll playfield |
| Ctrl+Z | Undo last placement/move |
| Ctrl+Y | Redo |
| Alt+S | Screenshot |
| Tab | Cycle through placed parts |

## Terminal-Specific Adaptations

Since this is a terminal game, UI must adapt:

### Mouse Support
- Terminal mouse events (crossterm/termion)
- Click, drag, scroll wheel
- Right-click via alternate button event

### Layout Responsiveness
- Minimum terminal size: 80×24
- Recommended: 120×40+
- Parts bin collapses to icons-only below 100 columns
- Control panel collapses to single-character icons below 90 columns

### Color
- Use terminal 256-color palette
- Fallback to 16-color for basic terminals
- True color (24-bit) for pixel renderer mode
