# Pyrotechnic & Ignition Parts — v1 Spec

## Overview

The ignition system handles light sources, fire, fuses, and explosives. It creates chain reactions through ignition transfer.

## Ignition Chain

The canonical chain: **Light Source → Magnifying Glass → Fuse → Explosive**

Alternative: **Laser → directly ignites fuses, candles, and pops balloons**

## Light Sources

### Flashlight

- **Type**: static part
- **Size**: 32×12px
- **Direction**: left or right (flippable)
- **Activation**: moving object must strike its switch (button on the back)
- **Output**: emits a visible light beam in the facing direction
- **Beam range**: ~200px
- **Interactions**: activates solar panels, provides light for magnifying glass

### Lava Lamp (Light with Drawstring)

- **Type**: static part
- **Size**: 16×32px
- **Has**: drawstring with rope attachment point
- **Activation**: drawstring must be pulled by weighted rope (attach rope to drawstring, route through pulleys, attach to weighted object)
- **Output**: emits omnidirectional light when activated
- **Light range**: ~100px radius
- **Interactions**: activates solar panels, provides light for magnifying glass

### Candle

- **Type**: dynamic part (feels gravity)
- **Size**: 8×16px
- **States**: `Unlit`, `Lit`
- **Ignition**: lit by magnifying glass beam, laser, or contact with another flame
- **Extinguished by**: fan airflow or bellows blast
- **Output when lit**:
  - Provides flame that ignites fuses on contact
  - Provides light for solar panels (~40px range)
  - Heats teapots placed directly below
  - Heats hot air balloons above
- **Special**: can be placed on conveyor belts to create a moving flame source
- **Mass**: 0.05, Elasticity: 0.1

## Magnifying Glass

- **Type**: static part, **untouchable during simulation** (objects pass through it)
- **Size**: 16×24px
- **Direction**: left or right (must match flashlight/lava lamp direction)
- **Behavior**: focuses incoming light into a concentrated beam
- **Input**: requires flashlight or lava lamp light aimed at it
- **Output**: focused beam that ignites any fuse, wick, or candle it hits
- **Beam range**: ~100px from the magnifying glass
- **Alignment**: light source and magnifying glass must face the same direction

## Fuse

- **Type**: static part
- **Shape**: line segment, positionable with two endpoints
- **Length**: adjustable (16px–200px)
- **States**: `Unburnt`, `Burning`, `Spent`
- **Ignition**: magnifying glass beam, candle flame contact, laser, or adjacent burning fuse
- **Burn rate**: ~60px per second
- **Burn direction**: from ignition point outward in both directions
- **Output**: burning end ignites anything it touches (other fuses, dynamite fuse, candle, cannon fuse, rocket fuse)
- **Visual**: glowing spark travels along fuse, spent portion turns dark

## Explosives

### Dynamite

- **Type**: dynamic part (feels gravity)
- **Size**: 12×20px
- **States**: `Idle`, `FuseLit`, `Exploded`
- **Ignition**: fuse attached to it must burn to the dynamite
- **Fuse burn time**: 1.5 seconds from ignition to explosion
- **Explosion effects**:
  - Destroys: brick walls, yellow brick walls, cinder block walls, wooden walls (within blast radius ~60px)
  - Does NOT destroy: inclines/ramps, metal piping, metal piping curves, earth/grass, caution walls, greco-roman walls, log walls, sand walls
  - Sends nearby dynamic objects flying (impulse ~2000 px/s outward from blast center)
  - Chain reaction: nearby dynamite (within ~80px) also explodes (0.1s delay)
- **Mass**: 0.5, Elasticity: 0.0

### Dynamite Plunger

- **Type**: static part
- **Size**: 20×28px
- **States**: `Ready`, `Pressed`, `Exploded`
- **Activation**: pressure on handle (dropping object on top, or pulling handle down via rope)
- **Explosion**: same blast effects as regular dynamite
- **Key difference**: does NOT chain-react from nearby dynamite explosions (only detonates from handle press)

### Cannon

- **Type**: static part
- **Size**: 48×24px
- **Direction**: left or right (flippable)
- **States**: `Loaded`, `FuseLit`, `Fired`
- **Ignition**: fuse on the cannon must be lit (same ignition chain as dynamite)
- **Firing**: after fuse burns (~1.0s), fires a cannonball in facing direction
- **Cannonball**: spawns a cannonball object with initial velocity ~1500 px/s
- **Recoil**: cannon slides backward slightly (~10px)

### Rocket

- **Type**: dynamic part (feels gravity before launch)
- **Size**: 12×28px
- **States**: `Idle`, `FuseLit`, `Launched`
- **Ignition**: fuse at bottom must be lit
- **Launch**: after fuse burns (~0.8s), launches upward with ~2000 px/s velocity
- **Post-launch**: burning trail can ignite fuses, candles, and pop balloons on contact
- **Mass**: 0.3 (pre-launch), effectively 0 during flight (constant thrust)

### Fireworks

- **Type**: dynamic part
- **Size**: 10×24px
- **Programmable**: three color slots for explosion colors
- **Behavior**: launches like rocket, explodes at apogee into colored sparks
- **Cosmetic**: explosion does not affect other parts

### Remote Control Bomb

- **Type**: dynamic part
- **Has**: rope attachment point
- **Activation**: detonates on signal (triggered by connected mechanism)
- **Explosion**: same as dynamite

### Match on Spring

- **Type**: static part
- **Behavior**: spring-loaded match that strikes and ignites on release
- **Output**: flame that ignites fuses and candles

## State Machine

```
enum IgnitionState {
    Idle,
    FuseLit { burn_progress: f32 },  // 0.0 to 1.0
    Exploded,
    Fired,
    Launched,
}
```

## Update Logic

Each tick:
1. Check light source activations (flashlight switches hit, drawstrings pulled)
2. Trace magnifying glass beams — check what they hit
3. Trace laser beams — check fuse/candle/balloon intersections
4. Update burning fuses — advance burn progress, check what burning end touches
5. Check dynamite/cannon/rocket fuse completion → trigger explosion/fire/launch
6. Process explosions — destroy surfaces, apply impulse to nearby objects, chain-react
