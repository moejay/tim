# Scoring & Progression — v1 Spec

## Overview

Tracks player progress through puzzles, manages sign-in profiles, and handles scoring for both single-player and head-to-head modes.

## Player Profiles

### Sign-In System

```rust
struct PlayerProfile {
    name: String,                        // player-chosen name
    created_at: DateTime,
    puzzles_solved: HashSet<PuzzleId>,
    puzzle_passwords: HashMap<PuzzleId, String>,

struct H2HStats {
```

- Create new profile: enter name at sign-in screen
- Select existing profile: choose from list
- Multiple profiles supported
- Profile data persisted to disk

## Single-Player Progression

### Puzzle Completion

When a puzzle is solved:
1. Puzzle marked as solved in player profile
2. Lightbulb icon changes to glowing state
3. Password for next puzzle is revealed
4. Score is updated based on bonus timers

### Bonus Timer System

Each puzzle has two countdown timers:
- **Timer 1**: generous time limit (e.g., 5 minutes)
- **Timer 2**: tight time limit (e.g., 2 minutes)
- Timers start when the player first presses the Green Flag
- Timer 1 completion: +100 bonus points
- Timer 2 completion: +250 bonus points
- Timers are cumulative — running simulation multiple times adds to total elapsed time
- Timers are per-attempt (reset if player restarts the puzzle entirely)

```rust
struct PuzzleAttempt {
    puzzle_id: PuzzleId,
    elapsed_time: Duration,
    run_count: u32,
    timer1_expired: bool,
    timer2_expired: bool,
}

fn calculate_score(attempt: &PuzzleAttempt) -> u32 {
    let mut score = 100;  // base score for solving
    if !attempt.timer1_expired { score += 100; }
    if !attempt.timer2_expired { score += 250; }
    score
}
```

### Tier Progression

| Tier | Unlock Condition | Puzzle Count |
|---|---|---|
| Tutorial | Always available | ~10 |
| Easy | Solve 5 Tutorial puzzles | ~35 |
| Medium | Solve 20 Easy puzzles | ~35 |
| Hard | Solve 20 Medium puzzles | ~35 |
| Expert | Solve 20 Hard puzzles | ~35+ |

### Password System

- Each puzzle has a unique 8-character password
- Password revealed upon solving the puzzle
- "Enter Password" option on puzzle selection screen
- Entering a valid password jumps directly to that puzzle
- Passwords are case-insensitive

```rust
fn validate_password(password: &str) -> Option<PuzzleId> {
    PUZZLE_PASSWORDS.iter()
        .find(|(_, pw)| pw.eq_ignore_ascii_case(password))
        .map(|(id, _)| *id)
}
```

## Head-to-Head Scoring

### Match Setup

```rust
struct H2HMatch {
    player1: String,
    player2: String,
    games_per_match: u8,     // 1–9
    time_per_turn: Duration, // 10–90 seconds
    rounds: Vec<H2HRound>,
    current_round: usize,
}

struct H2HRound {
    puzzle_id: PuzzleId,
    winner: Option<PlayerNum>,  // None = draw
    turns_taken: u32,
}

enum PlayerNum { Player1, Player2 }
```

### Round Scoring
- First player to press Green Flag and achieve the goal wins the round
- If neither player solves it and both agree to skip, round is a draw
- No points for individual actions — only solving the puzzle counts

### Match Scoring
- Match winner: player with most round wins
- Tie-break: if equal wins, match is a draw

### Auto-Save
- Profile saved after every puzzle completion
- Profile saved when exiting the game
- Profile saved after each head-to-head round
- No explicit "save game" action needed — progress is always persisted
