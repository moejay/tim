# Audio — v1 Spec

## Overview

Audio provides sound effects for physical interactions and background music. Audio enhances feedback and immersion.

### Music System

```
struct MusicPlayer {
    current_track: Option<TrackId>,
    volume: f32,         // 0.0 – 1.0
    is_playing: bool,
    loop_enabled: bool,  // always true for background music
}

impl MusicPlayer {
    fn play(&mut self, track: TrackId);
    fn stop(&mut self);
    fn set_volume(&mut self, vol: f32);
    fn next_track(&mut self);
}
```

### Music Controls
- Track selection: scrollable list in Music dialog
- Volume: slider (0–100%)
- Preview: plays immediately when selected
- Loop: music loops continuously during puzzle

## Sound Engine

### Architecture

```
struct SoundEngine {
    effects: HashMap<SoundEffect, AudioBuffer>,
    music_player: MusicPlayer,
    master_volume: f32,
    effects_enabled: bool,
    music_enabled: bool,
}

impl SoundEngine {
    fn play_effect(&self, effect: SoundEffect, volume: f32, pitch: f32);
    fn play_effect_at(&self, effect: SoundEffect, position: Vec2);  // spatial
    fn stop_effect(&self, effect: SoundEffect);
    fn set_master_volume(&mut self, vol: f32);
    fn toggle_effects(&mut self);
    fn toggle_music(&mut self);
}
```

### Sound Priorities
- Maximum simultaneous sounds: 16
- Priority system: newer sounds replace older ones if at capacity
- Exception: music track never gets replaced
- Spatial audio: sounds closer to screen center are louder (simple distance falloff)

### Volume Mixing
- Master volume × category volume × individual sound volume
- Categories: Effects, Music, UI
- Default: all at 100%

## Terminal Audio Considerations

### Implementation Options
1. **System audio**: use `rodio` or `kira` crate for audio playback
2. **Terminal bell**: fallback for terminals without audio support (`\x07`)
3. **No audio**: graceful degradation — game fully playable without sound

### Audio Detection
```
fn detect_audio_support() -> AudioMode {
    if can_open_audio_device() {
        AudioMode::Full        // rodio/kira playback
    } else {
        AudioMode::None        // silent mode
    }
}
```
